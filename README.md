📋 To-Do List Application

A simple, elegant, and feature-rich task management web application designed to help you organize your daily tasks with ease. This project features modern UI animations, theme switching, voice command integration, sorting, search, and full local storage support.

🚀 Features
✅ Core Features

Add, edit, and delete tasks

Mark tasks as completed

Add descriptions and due dates

Set priorities: High, Medium, Low

Responsive UI with modern animations

Preloader screen on load

🌓 Theme Mode

Light mode & Dark mode toggling

Theme preference stored using LocalStorage

🔎 Search & Sorting

Real-time search bar

Sort by:

High → Low Priority

Low → High Priority

Early To Do

Lately To Do

💾 Local Storage Support

Tasks remain saved after page refresh

Loads your saved tasks automatically

🧹 Clear All Tasks

Confirmation modals to prevent accidental deletion
